#2. Why is it important to use relative units (like %, vh, or rem) instead of fixed pixels (px) for responsive design?

Because relative units vh and % adapt to the screen size while fixed pixels stay the same size which causes content to be cut off or bigger than expected on mobile devices causing horizontal scrolling. px font values do not resize when users adjust their font settings on devices. Meanwhile rem scales alongside the font size settings from the user's browser.
