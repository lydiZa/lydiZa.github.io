#1. Describe the path an HTTP Request takes from a browser to your GitHub Pages site.

An HTTP Request (GET) asks for server's resource.
When I type in the URL, my browser looks it up on the internet and locates its IP address. 

It connects my browser to GitHub's server. The server extracts the URI from the request line, locates the file in its disk, and sends back a HTML Response; displaying HTML and images to my browser screen.
